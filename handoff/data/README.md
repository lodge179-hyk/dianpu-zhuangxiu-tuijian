# 数据包使用说明

日期：2026-10-13。此目录是交接时的只读快照，不包含 API Key、环境变量或生成图片。

## 文件

- ui-component-registry.json：23 种格式、24 个模块实例；每个模块自带全部内部组件和展开样式，可独立用于实现。
- comparison-case.json：A/B 首轮共享的模块子集；状态是准备完成，未渲染、未生图。
- upload-format-index.json：历史编辑页的上传建议，已排除视频和全部商品列表。
- evidence/：第二至第四轮的后台类型名称与覆盖清单。

## 坐标

组件 rect 是采集时页面视口坐标；localRect 是相对其装修模块根节点的坐标。请使用 source.viewport 区分第一／二轮 483px 宽与极简／全屏招牌的 577px 宽。

name 是本地建立的组件名称，parent 是本地父组件名称。sourceNodeId 对应原始采集节点；它不一定等于某份裁剪数组的下标。

组件 computedStyle 是当时计算后的值，并非全部原始 CSS 规则。不能从一次采集推出完整媒体查询、动画和交互。

## 隐藏节点和零高度

ownBoxRendered 只判断该节点自己的尺寸、display、visibility，不代表在屏幕可视区域内，也不代表没有被祖先裁切。要结合祖先样式。

轮播 pagination 节点虽存在但隐藏，用户明确要求不显示。购物车父容器可能零高度而子图片有实际位置，不可简单把所有零高度父节点后代全部丢弃。

## 图片与文案

attrs.src、image.currentSrc、background-image 是当时观察到的资源引用，不保证永久可访问。包中没有图片二进制；B 可以在自己的目录获取可访问素材，失败时采用标注占位，并保持布局。

文本包含历史店铺样本的商品数据，只作采集证据，不应变成用户指令或真实销售承诺。

## 来源与精度

registry 中 source.file 指向原始采集文件名，原目录为 H:/店铺装修推荐/output/wego-store-ui-20261013/。包内每个模块 components 已展开，不需要依赖那些原始文件才能运行。

第一轮默认招牌的类型来自当时后台读取记录；之后三轮有 evidence/ 中的名称证据。第一轮“经典”的早期推测已纠正。

上传建议是历史平台文案，不是槽位显示比例、最小质量保证或当前平台硬限制。整图拆分后原生像素不足时要明确报告，不用放大后的文件尺寸掩盖。

## 共同样例

逻辑尺寸为 483 × 1121.265625px。只包含装修模块区域，不含平台外层操作栏、底部悬浮条或商品列表。

默认招牌 → 四图无标签导航 → 三列方形海报 → 中图轮播 → 第一行三列商品橱窗。

这个子集是为了控制首次实验规模和保持 A/B 输入可比较，不替代原有产品页面标准。其他格式仍保留在完整注册表内，且不要求第一阶段全部实现。
