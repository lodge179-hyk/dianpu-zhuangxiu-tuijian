本轮交付：固定 UI 组件内部封装
日期：2026-10-13

一、保留当前认可的效果
以 A8「完整店铺长图」为基线，不调整已认可的排版、尺寸、样式和内容。
AI 选用模块的目录暂不定义，不增加全模块预览页面，不接入或重写现有应用。
所有新文件均位于 a9-component-library，A8 文件保持原样。

二、封装结果
lib/index.cjs：组件调用入口，导出 renderPage、renderModule、components。
lib/modules/：招牌、图片区域、商品橱窗、文字区域四组渲染实现。
lib/styles.snapshot.json：已有抓取数据的几何位置和样式快照。
lib/layout.css：沿用 A8 的排版样式。
lib/icons.json：固定 UI 图标，不需要重新生成。
example/page.json：店铺信息、图片、文案、商品信息和模块顺序。
example/assets/：仅供示例使用的现有素材。
example/shop.html：通过上述数据和组件重建的 A8 页面。

共封装 23 种已有模块样式，覆盖招牌、导航、海报、轮播、商品橱窗、文字。
组件内部按模块 ID 和子组件名称定位；子组件位置由固定样式决定。
图片、文字、商品数据作为参数传入，调用方无需编写 HTML 或 CSS。
这里的内部组件注册表是程序实现，不代表已确定 AI 的选型目录或决策规则。

三、最小用法
const { renderPage } = require('./lib/index.cjs');
const page = require('./example/page.json');
const result = renderPage(page);
// result.html 为完整 HTML；同时返回尺寸、子组件位置与图片槽位信息。
// 将 HTML 保存至 example/shop.html，可直接使用示例中的相对素材路径。

修改示例内容后，运行：
node build-example.cjs

更换素材时保留模块 type 和固定布局，只修改对应 content。
模块顺序由 modules 数组决定。每个模块必须使用唯一且稳定的 id。
不接受调用方传入任意位置、间距或 CSS；超出已支持的参数会直接报错。
轮播保留当前静态参考图状态，没有指示点；不包含视频。
