# 整页生成验收补充：轮播与海报

按用户确认的参考结构验收：

- 会员权益/积分商城为固定平台区域，按原长截图保留薄浅米色横条、小号橙色线框徽标与礼物图标、小号细字和浅色箭头；不可改成实心皇冠、金币堆、大号粗字的营销卡片。

- 轮播图片左右贴页面边缘，外侧边距为零。
- 轮播四个角均为直角，圆角半径为零；底部两个角也不得出现圆角裁切或白色缺口。
- 商品橱窗每格图片宽高相等，名称与购物车位于图片外的信息区；不可拉长图片或商品以填满画布。
- 海报整行左右贴页面边缘，外侧边距为零。
- 轮播与海报相邻时，之间只有一条细白线，没有大块白色间距。
- 每张海报之间只有一条细白线，没有宽沟槽。
- 海报扣除分隔线后等分整行，保留用户认可的竖向比例；当前样图目视约宽:高=1:1.3，仅为本轮近似目标，不是平台通用尺寸。不能因海报非正方形判错，也不能为填充而拉伸商品。
- 轮播指示点放在图片内部，避免独立指示点条带撑开模块间距。

细白线的精确像素值尚未由用户指定，按参考图的视觉细线验收，不将具体像素数冒充用户要求。此文件为人工验收规则，不代表已实现自动检测。

此修订用于后续任务。既有稳定性测试的提示词、原图与记录保留不变。
