# 当前整页样板规格 v1

范围：当前心意彩妆页面，三个原始礼盒商品。不是平台全部22种格式的统一尺寸表。W为整页宽度；素材上传建议、页面显示槽位与包含文字的模块高度分别理解。

| 模块 | 已确认要求 | 当前生成目标及来源 | 尚未确定 |
| --- | --- | --- | --- |
| 招牌 | 双绿色三角背景固定，昵称与头像可变，保留平台操作栏 | 本地固定背景1240×880，高约0.71W；属参考图比例 | 所有招牌格式通用高度，不在本轮确定 |
| 平台权益区 | 保留会员权益/积分商城 | 沿用当前页面的浅色横条 | 精确高度和字体像素 |
| 导航 | 当前四个；正圆等大，四/五列只影响排列，不改变大小；图下标签 | 当前目标直径0.15W，源于前轮设定及参考观感；168×168是旧截图上传建议，不是显示直径 | 平台精确显示直径 |
| 轮播 | 左右贴边，完整商品，指示点在图内，与海报仅细白线相隔 | 当前沿用中图4:3；旧原始中图截图建议1080×810 | 其他档位不在本轮切换 |
| 三列海报 | 当前用户接受竖向海报，三格等宽、等高，整行贴边，仅细白线分隔 | whole-page-edge-v1目视宽:高约1:1.3，本轮近似复现；扣除线宽后等分 | 平台各海报格式的精确显示比例；不得把上传建议1080×1080当成方形显示要求 |
| 商品橱窗 | 三列，方形商品图，名称在图下，价格空缺不编造，购物车在每卡信息区右下方 | 图宽约0.30W，沿用当前页面；方形仅指图片，不含文字区 | 全分辨率固定边距和字体像素 |

顺序：招牌 → 权益区 → 四个导航 → 轮播 → 三列海报 → 三列商品橱窗。

白线：用户确认视觉细线；旧预览写1px，本轮提示词约0.002W为实现目标，不能冒充精确平台规定。

验收分两层：先检查上述用户确认的结构，再记录近似目标偏差。商品被拉伸、组件遗漏、包装改变另行记录，不能用模块容器比例合格代替商品保真合格。

历史生成图和提示词保留，活动入口whole-page.mjs及layout-acceptance.md已删除海报必须正方形的约束。
