# 店铺结构规划执行与验收

日期：2026 年 10 月 14 日。工作分支：`codex/store-planning-workflow`。基线：`d6a81fa`。

## 目标与交付

在现有装修实验中加入可比较、可解释的结构选择，再把选中的结构接入素材规划、裁剪、预览和下载。判断结构是否更好由用户评审；程序只保证约束、数据来源和执行结果可核对。

交付包括：可操作的结构比较入口、带来源与适用边界的小型组合方案库、逐位置素材任务、同店两种组织方式及第二类店铺示例、测试与浏览器验收记录、使用说明，以及分支提交和推送。禁止合并。

## 实施顺序

1. 先保存本执行文档，再修改应用代码。
2. 建立有来源的组合方案及明确的数据结构；先完成约束和灰度结构比较。
3. 接入店铺资料和已有方案。截图入口先提取可辨识资料，再生成结构候选；不把完整生图方案冒充结构分析。
4. 选择候选后生成符合现有 schema 的素材方案，进入原有裁剪与下载链路。
5. 验证美妆与服装两类资料、旧方案兼容、失败处理及浏览器操作。记录实际完成程度，不将规则生成称为模型推理，不将占位图称为真实生成结果。
6. 更新本文与 README，检查本次改动后提交、推送分支并核对远端。

## 本轮范围

- 内容组织先比较分类浏览和主题展开。页面长度作为独立选项，采用相同资料和相近内容预算比较，不将紧凑长度当作第三种组织方式。
- 每套方案解释目标、适用条件、内容顺序、取舍和来源。每个模块注明用途、位置理由及删去条件。
- 灰度预览使用现有组件几何，标注为结构示意，不添加平台没有的交互或控件。
- 先覆盖 2 至 5 个明确品类；无法可靠识别的资料须提示补充或回退到原有入口，不擅自补造品类。
- 素材任务区分识别、主题、场景和细节；统一色彩与质感，允许镜头和环境变化。素材仍为品类示意。
- 保持 23 种固定组件、12 张独立素材、2 批总图、每批最多 6 张的约束。模块数量按任务决定，不强制凑满 8 至 12 个。
- 保留已有运行记录和旧 JSON 导入。继续使用原有手动总图上传与下载流程。

## 可动态优化的范围

允许根据代码与测试证据调整：候选的模块数量及顺序、现有变体选择、长度预算、说明文字、资料字段、素材角色、批次编排、比较界面的信息层级，以及保持兼容所需的接口和校验。新增或删减功能须在下方变更记录写明原因、影响和验收方式。

不能自行扩大为：新增平台组件、自由修改店铺 UI 几何、抓取大量图库、接入新的付费服务、自动发布到电商平台、重构主应用、覆盖旧任务、训练模型、建立复杂自动评分系统、承诺转化率，或合并分支。

本轮优先复用现有图片检验装配；如新结构需要新素材，明确显示未填入状态。不得静默沿用含义不匹配的旧图，也不把人工介入隐藏成自动能力。

## 验收条件

| 编号 | 条件 | 证据 |
| --- | --- | --- |
| A1 | 相同店铺资料和长度设定产生两套组织逻辑有差异的候选 | 模块顺序、任务与来源可见；自动校验 |
| A2 | 结构选定前不创建生图批次；选择后任务与每个槽位对应 | 接口与界面检查 |
| A3 | 模块、比例、素材、批次通过原有校验，无虚构经营事实 | 有效及无效输入测试 |
| A4 | 灰度结构按真实槽位呈现；没有伪造导航文字或交互 | 浏览器查看并保存证据 |
| A5 | 已有方案和下载不回归，选用结构产生新任务 | 原有测试及端到端接口检查 |
| A6 | 同一规则用于美妆和服装资料，不把美妆叙事套到服装 | 两类示例及人工查看 |
| A7 | 能区分规则生成、截图模型分析、已有素材复用和待生成素材 | 界面说明及交付记录 |
| A8 | 提交仅含本轮必要代码、文档、可复现示例；无凭据和原始截图 | git diff、测试结果、远端提交核对 |

## 来源与迁移边界

- [MUJI](https://www.muji.us/)：场景主题与明确分类并存。借鉴浏览任务，不复制其六分类布局或品牌素材。
- [Glossier](https://www.glossier.com/)：主视觉、比较、分类与编辑内容承担不同任务。不能从观察推断转化率。
- [ILIA](https://iliabeauty.com/)：不同图片角色共同服务页面。选购工具、评价等需要真实资料，本轮不实现。
- [美图设计室](https://www.designkit.cn/help/147)：配图类型配置接后续长页组装；单商品套图数量不照搬到整店。
- [Figma Weave](https://help.figma.com/hc/en-us/articles/41159711083543-AI-workflows-collection-Bring-imagery-into-your-designs)：构图与图片任务相互配合，工作流复用不等于同一画面复制。
- [Kittl](https://help.kittl.com/editing-and-design/set-up-and-apply-your-brand/)：共享视觉规则和允许变化的边界分开表达。
